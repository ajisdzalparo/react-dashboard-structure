===============================================================================
                         QUICK START (2 MINUTES)
===============================================================================

1. IMPORT
   import { Table, Pagination, TableContainer } from '@/components/Table';
   import { useTable } from '@/hooks/useTable';

2. DEFINE DATA
   interface User { id: number; name: string; }
   const columns = [{ key: 'name', label: 'Name' }];
   const data = [{ id: 1, name: 'John' }];

3. PAGINATE
   const { paginatedData, currentPage, totalPages, goToPage } = useTable({
     data: data,
     itemsPerPage: 10,
   });

4. RENDER
   <TableContainer footer={<Pagination ... />}>
     <Table columns={columns} data={paginatedData} rowKey="id" />
   </TableContainer>

THAT'S IT! ✅

===============================================================================
                       TROUBLESHOOTING
===============================================================================

❌ Table not updating
✅ Make sure rowKey is unique and stable
   Check that data reference is new, not mutated

❌ Pagination not working
✅ Verify totalPages is calculated correctly
   Check onPageChange updates state

❌ Styling looks wrong
✅ Import Tailwind CSS in globals.css
   Check className syntax
   Use cn() utility for conditionals

❌ Loading state not showing
✅ Pass isLoading={true} to Table
   Remove or clear data when loading

❌ Empty state not showing
✅ Check isEmpty prop or data.length === 0
   Verify emptyMessage is provided

For full troubleshooting → TABLE_QUICK_REFERENCE.md
