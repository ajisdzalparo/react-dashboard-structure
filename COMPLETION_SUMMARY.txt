================================================================================
                            CUSTOMIZATION QUICK TIPS
================================================================================

🔧 Change Sidebar Menu:
   File: src/components/Sidebar.tsx
   Edit: NAV_ITEMS array

🎨 Change Colors:
   File: tailwind.config.js
   Edit: theme.extend.colors

➕ Add New Page:
   1. mkdir -p app/dashboard/pagename/
   2. touch app/dashboard/pagename/page.tsx
   3. Copy structure from dashboard/page.tsx
   4. Add to NAV_ITEMS in Sidebar.tsx

🔗 Connect API:
   File: src/services/api.example.ts
   Reference: Complete API integration example
